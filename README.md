# Уютные слова (прототип)

Казуальная мобильная игра из связанных мини-игр. Чистый JS, без сборки.

## Запуск

```bash
node serve.mjs
```

Открыть http://localhost:8765 (в DevTools включить мобильный режим). Чтобы открыть с телефона в той же Wi-Fi сети — http://<IP компьютера>:8765.

## Экономика

Каждая игра перерабатывает то, что добыла другая:

```
🎯 Блоки (бесплатно)        → буквы
🔤 Эрудит: буквы            → карточки-слова (СТОЛ, ЛИЛИЯ), предметы (КОТ), эссенции (ЛЮБОВЬ), комнаты (КУХНЯ)
🃏 Пасьянс (⚡4): карточки  → собранная категория превращается в предмет + 🗝️
🍬 Три в ряд (⚡5): 3–6 своих предметов как фишки → +2 за каждую цель + 🗝️
🔍 Поиск (⚡6, 🗝️ на локации) → новые виды предметов
🔥 Печь: дубли, эссенции    → ⚡; 3 одинаковых → предмет получше; улучшение за 🗝️

Валюты: только ⚡ энергия, буквы и 🗝️ ключи (монет нет).
📋 Заказы соседей: наборы из разных игр → энергия, ключи, редкие предметы
🏠 Квартира: предметы → уют; комнаты открываются словами в Эрудите
```

Подсказки: цепочка заданий в хабе, строка готовности на каждой карточке игры («что нужно и где взять»), правила при первом запуске каждой игры.

## Словарь

`tools/russian_nouns.txt` — ≈51 тыс. существительных ([Harrix/Russian-Nouns](https://github.com/Harrix/Russian-Nouns), MIT).
`tools/dict-labels.txt` — разметка слов по категориям (короткие слова до 8 букв размечены нейросетью; абстрактные суффиксы -ость, -ние, -ство… автоматически становятся эссенциями).
Пересборка: `node tools/build-dict.mjs` → `src/data/dict.json`.

## Структура

- `src/state.js` — состояние игрока и сохранение в localStorage
- `src/data/items.js` — каталог предметов (ярус 1), категории, комнаты, `classifyWord`
- `src/data/words.js` — словарь прототипа: карточки-слова (ярус 2) и эссенции (ярус 3)
- `src/data/letters.js` — алфавит, очки и частоты букв
- `src/screens/` — персонаж, дом, сумка, печь, хаб игр
- `src/games/` — мини-игры, контракт в `src/games/CONTRACT.md`

В консоли браузера доступен `game.store` для отладки (например `game.store.addLetters('КУХНЯ')`).
